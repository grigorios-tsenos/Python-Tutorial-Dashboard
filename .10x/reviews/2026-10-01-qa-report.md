## Bugs found during verification, all fixed
1. Celebration modal could pop up 700 ms later on a different page → pending celebration cancelled on leave and replaced by toasts; modal also closes on navigation.
2. Command palette lost fast typing after ⌘K (focus race) → `autoFocus`.
3. Palette only searched titles ("cosine" found nothing) → also searches id, tagline, track, kind.
4. `.badge` CSS class shared by achievements, celebration rows and toasts → grayed-out rows in the celebration; renamed.
5. Map hero panel covered the NumPy constellation and whole-sky zoom made stars tiny → map opens focused on the current constellation, aimed away from overlays; Fit button for the full sky.
6. Visual Labs rendered below checks/console → visual first for lab lessons.
7. Radar labels clipped; prev/next buttons truncated from the left; "1 days"/"1 cards" plurals.
8. (Content) shim gaps found by writing lessons: SQL three-valued logic, aggregates wrapped in expressions (`F.round(F.sum(..), 2)`).

## Not covered / known gaps
No automated tests on Firefox/Safari (CodeMirror, module workers expected to work). No accessibility audit with a screen reader (ARIA roles/labels, focus rings and keyboard paths are in place; Parsons supports Alt+Arrows). Touch pinch-zoom on the map is not implemented.
